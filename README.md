# Assignment: Problem Solving with TypeScript & OOP

## Assignment Overview

This assignment demonstrates practical TypeScript skills from Modules 1,
2, and 3. It covers basic types, optional parameters, union types and
type narrowing, readonly tuples, rest parameters, interfaces, generics,
Promises, and object-oriented programming (OOP).

All coding solutions are kept in a single file named `solutions.ts`.

## Problems Covered

1.  **Optional Parameters** --- Multiply a number by an optional
    multiplier, using `2` when the multiplier is omitted.
2.  **Union Types and Type Narrowing** --- Process string, number, and
    boolean inputs safely with `typeof`.
3.  **Readonly Tuples** --- Format a coordinate tuple as a location
    string without modifying it.
4.  **Generics and Rest Parameters** --- Combine multiple arrays
    containing elements of the same type.
5.  **Interfaces and Array Filtering** --- Define a `Course` interface
    and return published courses that meet a minimum student count.
6.  **Generic Constraints (`keyof`)** --- Extract values for a selected
    property from an array of objects.
7.  **Object-Oriented Programming** --- Implement an `Employee` base
    class and a `Manager` subclass using access modifiers and
    inheritance.
8.  **Promises and Async Operations** --- Validate an age
    asynchronously, resolving with the required success message or
    rejecting with an `Error` when access is denied.

## Running the Solutions

Make sure Node.js and TypeScript are installed. Compile the TypeScript
file with:

``` bash
tsc solutions.ts
```

Run the generated JavaScript file with:

``` bash
node solutions.js
```
